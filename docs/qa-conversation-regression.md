# 对话页回归用例（消息 / 滚动 / 连接）

> 覆盖最近修复的几类问题：消息被吞、顺序错乱、回到底部箭头、自动滚动、401、取消发送。
> 自动化部分见 `DSHPocketUITests/DemoFlowUITests.swift`；以下为需要真机的补充用例。

## 前置

- Mac 端 DSH 运行中，`dsh-pocket-ios` 已安装并开启；Tailscale 与 `tailscale serve --bg 3091` 正常（或使用 dsh-pocket 局域网）。
- 手机与电脑已连接，进入任意会话。

## A. 发送与消息保留

| # | 步骤 | 预期 |
| --- | --- | --- |
| A1 | 空闲时发送一条纯文字 | 气泡立即出现（发送中），随后保持可见并排在回复上方 |
| A2 | AI 正在输出时发送一条（steer） | 气泡立即出现，不闪没；回复/过程随后继续出现在它下方 |
| A3 | A2 后等待 10 秒 | 消息仍在，不出现“重新发送”误报 |
| A4 | 发送带图片的消息（多选 2 张） | 图片与文字同气泡；发送后不消失 |
| A5 | 连续快速发送 2 条 | 两条都保留，顺序与发送顺序一致 |
| A6 | 发送过程中切到别的会话再切回 | 消息完整（不重复、不丢失） |

## B. 顺序

| # | 步骤 | 预期 |
| --- | --- | --- |
| B1 | 已有过程行后发送消息 | 你的消息在旧过程行之后 |
| B2 | 发送后产生新的工具调用 | 新过程行在你的消息之后，不会跑到上方 |
| B3 | 一轮结束 | 顺序为：你的消息 → 过程（折叠）→ 助手回复 |
| B4 | 发送的消息带引用（长按引用） | 引用卡片在气泡内，位置正确 |

## C. 滚动与“回到底部”

| # | 步骤 | 预期 |
| --- | --- | --- |
| C1 | 发送消息 | 自动滚到最新，不出现箭头 |
| C2 | AI 持续输出 | 保持贴底跟随 |
| C3 | 手动上滑后 AI 继续输出 | 不被拽回；箭头按规则出现 |
| C4 | 上滑但只有 ≤5 条新消息 | 箭头不出现（或按产品规则：>5 才出现） |
| C5 | 点箭头 | 回到底部、恢复跟随、箭头消失 |
| C6 | 箭头出现时 | 不遮挡刚发送的用户消息（0.9s 防抖） |

## D. 连接与登录

| # | 步骤 | 预期 |
| --- | --- | --- |
| D1 | Mac 重启 DSH 后在 App 拉列表/发消息 | 自动回连接页，提示“登录已过期（DSH 可能重启过），请重新扫码配对或输入访问密码” |
| D2 | 重新扫配对二维码 | 直接进入会话列表，无需密码 |
| D3 | 断开连接按钮 | 弹确认框；取消保持连接，确认才断开 |
| D4 | 手机开小火箭后连 Tailscale 地址 | 连不上属预期（VPN 互斥），切方式二局域网 |
| D5 | 配对二维码过期（>60s） | 提示失效，等新码重扫 |

## E. 其它回归

| # | 步骤 | 预期 |
| --- | --- | --- |
| E1 | 发送过程中看右下角 | 只有绿色发送按钮，无红色取消叉 |
| E2 | 齿轮 → 语言 → English | 整个界面切英文并持久化 |
