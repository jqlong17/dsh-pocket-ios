DSH Pocket iOS — 支持

把 DeepSeek Harness 装进口袋的 iOS 客户端

快速开始

  1. 在电脑上安装并启用 dsh-pocket 插件（DeepSeek Harness 桌面端 → 插件）；
  2. 打开该插件的「手机访问」页，用手机扫描二维码，或在 App 里手动输入 http://电脑IP:端口 与访问密码；
  3. 连接后即可查看会话、收消息、发消息、发图片。

没有电脑？

在连接页点「体验演示模式」，用内置示例数据查看界面；演示模式不会连接任何服务器。

常见问题

  • 连不上：确认手机与电脑在同一 Wi‑Fi，电脑上的 dsh-pocket 已启用；地址与端口以「手机访问」页显示的为准（默认 3081，可改）。
  • 提示密码错误：以「手机访问」页显示的访问密码为准；修改后需要重新输入。
  • 实时消息停住：App 会自动重连；也可下拉刷新会话列表。
  • 安装：App 通过 GitHub Release 以自签方式安装，签名到期后重新签一次即可。

反馈

问题、建议或安全报告请提 GitHub Issues。

Support (English)

DSH Pocket iOS is an iOS client for DeepSeek Harness. Install and enable the dsh-pocket plugin on your computer, then scan its QR code (or enter the LAN address and PIN) in the app. No computer at hand? Use “Demo mode” on the connect screen. Report issues on GitHub Issues.
